personal-assistant: Privacy policy

Last updated: 17 November 2026

Who uses this app

personal-assistant is used only by its owner, with the owner's own Google account. It is not offered to other users.

What Google data it accesses

The app requests the Google Tasks scope (https://www.googleapis.com/auth/tasks). It reads the owner's task lists and tasks, creates tasks, edits task titles, notes and due dates, and marks tasks complete or not complete. It does not delete tasks or task lists, and it does not access any other Google data.

How the data is stored and used

The app runs on the owner's computer. The sign-in token Google issues is stored only on that computer, in a file readable only by the owner. Task data is retrieved when the owner's AI assistant (Claude, provided by Anthropic) asks for it on the owner's behalf, and is used only to answer the owner's own requests about their tasks.

Sharing

Task data is not sold, not used for advertising, and not shared with anyone other than the AI assistant the owner uses to process it.

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions, and by deleting the token file from the owner's computer.
